Building a Vulnerable Machine – Cybersecurity Training Lab

This project presents a custom-built vulnerable virtual machine designed for hands-on cybersecurity and penetration testing training.
It simulates real-world security misconfigurations and common vulnerabilities within a university-themed environment.

🎯 Objectives

Provide a safe, controlled environment for ethical hacking practice

Demonstrate real-world vulnerabilities and exploitation techniques

Enhance practical skills in reconnaissance, exploitation, and privilege escalation

⚙️ Technologies & Services

Ubuntu Server 18.04

FTP (Anonymous Login)

SSH (Weak credentials / misconfiguration)

SMB (Weak authentication)

Apache + PHP

MySQL (SQL Injection)

Cronjob PATH Misconfiguration (Privilege Escalation)

🧨 Implemented Vulnerabilities

FTP Anonymous Access

Weak & Reused Credentials

Steganography (Hidden credentials in files)

SQL Injection with filter bypass

SMB Misconfiguration

Cronjob PATH Exploitation

🧑‍🎓 User Roles

university – low privilege

electrical – higher privilege

root – full system control

🧭 Learning Outcomes

Network & service enumeration

Web exploitation (SQLi)

Credential harvesting

Privilege escalation techniques

Realistic attack-chain methodology

🎓 Academic Context

Lebanese University – Faculty of Engineering III
Communication & Mini-Project (Spring 2024–2025)

⚠️ Disclaimer: This machine is created strictly for educational purposes.
Do NOT deploy in production or real networks.
